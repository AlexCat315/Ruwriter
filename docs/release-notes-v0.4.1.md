# Ruwriter v0.4.1

这一版收尾两件事：侧栏入口重做，以及把中文输入法在编辑器里的几个硬伤修掉。

## 侧栏：底栏永远只有一行

- 底栏固定为单行「云同步 · 未同步 / 上次同步时间」，点击展开设置卡片；云同步与外观都收在卡片里。
- 以后新增功能继续进这张卡片，不再往底栏叠第二行、第三行。
- 卡片与侧栏留出 8pt 边距、10pt 圆角，深色 / 浅色主题一致。
- 选择外观后卡片自动收起；点「打开云同步…」也会像菜单一样收起，再弹出同步面板。
- 修复「文件 → 云同步…」与侧栏入口点击后对话框不出现的问题：入口只改了状态，根视图没有重绘。

## 输入法：不再把原始拼音写进正文

- 拼音分隔符（撇号）不再被当作普通文本提交，正文不会留下 `'`、`‘’` 或 `“”`。
- 拼音候选窗打开时点击别处，会丢弃还没上屏的合成串，而不是把 `dsaasd`、`d'sa'as'd` 这样的原始拼音 commit 进文稿；候选窗同时消失，不再挡住后续点击。
- 点击取消输入时，平台层先丢弃 marked text 再拆输入框，避免 AppKit 在移除 responder 时把未上屏拼音提交出来。
- 点到桌面、切到别的应用导致失焦，也不会再把合成串写进正文。

## 光标定位

- 鼠标按下时先在当前滚动位置算出落点，再改变焦点；焦点触发的光标滚动不会让点击落到邻行。
- 向上跨行点击、候选窗打开时换行点击都已回归验证。

### 安装说明

- macOS：打开 `.dmg`，把 `Ruwriter.app` 拖进「应用程序」。当前包没有 Apple 开发者签名与公证，首次打开请右键「打开」，或到「系统设置 → 隐私与安全性」允许。
- Windows：运行 `Ruwriter-v0.4.1-windows-x64-setup.exe` 安装。未签名，SmartScreen 提示时选择「更多信息 → 仍要运行」。
- Linux：`sudo apt install ./Ruwriter-v0.4.1-linux-x64.deb`，需要系统具备 Vulkan 与常用 X11 / Wayland 图形库。
- iOS 与 Android 需要各自的签名材料，本次不提供移动端安装包。

下载后可用同一 Release 里的 `SHA256SUMS.txt` 校验文件完整性。

## 已知限制

- 云同步依赖 GitHub CLI；未安装 `gh` 时面板会给出安装与登录提示。
- Gist 单文件有平台上限，超大文稿或附件不适合作为同步载体。
- macOS 包最低系统版本由 Cove 打包配置决定，目前为 macOS 26。
- 没有代码签名，首次运行会被系统拦截一次。
- Windows 高 DPI 下的鼠标点击定位仍在实机验证；如果遇到整体偏移或越往上越偏，请附上缩放比例与点击位置。
