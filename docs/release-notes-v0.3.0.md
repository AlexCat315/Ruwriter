# Ruwriter v0.3.0

面向小说作者与文字工作者的跨平台写作软件。v0.3.0 把默认写作方式改成真正的纯文本，并补齐长篇写作最常用的排版与恢复能力。

## 这一版的重点

- **默认小说模式**：新稿是 `.txt`，正文里没有 Markdown 记号，也不显示格式按钮；宋体 / 衬线正文、较松行距，章节靠「第一章」这样的行分。
- **段首缩进与章节标题顶格**：正文每段首行缩进两个字，折行回左；章节标题不缩进。缩进只存在于排版层，正文文件不含空格或 Tab。
- **中文章节大纲**：识别「第一章」「第三卷」「第十二回」「楔子」「尾声」「番外」等章节行，常驻右侧，点击跳转。
- **历史版本**：每 10 分钟和打开文稿时自动留纯文本快照，最近 30 份；⇧⌘S 手动保存，「文件 → 历史版本…」可恢复，恢复也能 ⌘Z 撤回。
- **排版可调**：字号、三档行距、三档正文栏宽、打字机滚动，都只改显示，不碰正文文件。
- **回到上次位置**：每篇文稿记住停笔处，切换文稿或重启后回到那一段。
- **长文性能**：4 万字以上改为停笔 0.3 秒后整篇落盘，20 万字文稿输入不再每键重写文件。
- **命令面板**：⌘K 可执行全部命令、跳转文稿与大纲。

### 安装说明

- macOS：解压后把 `Ruwriter.app` 拖进「应用程序」。当前包没有 Apple 开发者签名与公证，首次打开请右键「打开」，或到「系统设置 → 隐私与安全性」允许。
- Windows：解压整个文件夹后运行 `Ruwriter.exe`。未签名，SmartScreen 提示时选择「更多信息 → 仍要运行」。
- Linux：解压后运行目录里的 `Ruwriter`，需要系统具备 Vulkan 与常用 X11 / Wayland 图形库。
- iOS 与 Android 需要各自的签名材料，本次不提供移动端安装包。

下载后可用同一 Release 里的 `SHA256SUMS.txt` 校验文件完整性。资料库默认位于用户数据目录，可用 `RUWRITER_DATA_DIR` 指定；正文是普通 `.txt` / `.md` 文件，`.ruwriter/` 只保存派生状态与快照。

## 已知限制

- macOS 包最低系统版本由 Cove 打包配置决定，目前为 macOS 26。
- 没有代码签名，首次运行会被系统拦截一次。
- 退出前不足约 1.2 秒的光标移动可能来不及写入上次位置。
