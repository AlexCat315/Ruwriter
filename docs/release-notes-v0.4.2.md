# Ruwriter v0.4.2

这一版把云同步收稳，并把编辑器对齐 Cove 上游最新的文本字段：每个资料库各自记账，冲突副本先落到本地再上传，同步中途继续写作也不会被覆盖。

## 云同步：按资料库各自记账

- 同步标识、Gist ID、上次同步时间与三方基线从全局 `library.json` 移进资料库的 `.ruwriter/state.json`；v0.4.1 及更早的配置在打开资料库时自动迁移一次。
- 换电脑时复制整个资料库文件夹（含隐藏的 `.ruwriter` 目录），登录同一个 GitHub 账号即可接着同步。
- 切换资料库后不再显示上一篇资料库的上次同步时间与结果；云端 Gist 属于另一个资料库时直接报错，不会把别的文稿写进来。

## 云同步：不再吞掉正在写的内容

- 同步开始前先把未落盘的长文缓冲写入并刷新摘要、大纲，再和云端比对。
- 本地与云端同时改过一篇时，先把云端版本存成「原名（云端冲突 日期 时间）.txt」，确认写成功后才上传本地版本；60 秒内没保存成功就中止本次同步，不会只提示「已保留」而实际没写。
- 同步开始后又改过的文稿不会在拉取时被云端版本覆盖：保留本地版本、推迟到下一次同步，状态栏提示「同步期间有 N 篇在本地修改，请再次同步」。
- 重命名、换文件夹、改扩展名会跟着同步移动本地文件，而不是新建一份或覆盖旧文件。
- 「检查登录」改为打开面板时异步执行，检查中与同步中禁用重复点击；状态区可显示 5 行。

## 编辑器

- 字数、摘要、预览与大纲在文本变化后统一重算，不再分散在各条编辑路径上；待落盘缓冲改用 `TextBuffer`，长文停笔写入前先更新摘要。
- Markdown 格式化的光标与选区按字素簇换算，中文、emoji 下加粗、链接、列表、删除线之后撤销与选区不再错位；状态行「已选 N 字」与正文计数一致。
- 回车续行只改当前行，行首列表前缀区域内回车不再误拆列表项。
- ⇧⌘X 删除线优先于系统的剪切；输入法合成期间 Esc、方向键、退格、Tab 不再触发应用快捷键，候选串不会被提交进正文。
- 正文区改由文本字段自身滚动，长稿滚动发生在正文内部。

## 编辑器补丁并入 Cove 上游

- 文本字段滚动后的点击与拖选现在以屏幕上已绘制的行位置为准：点自动折行的行尾，光标留在点击的那一行；正反向跨段拖选都落到正确字位置。
- 这些改动此前以 `patches/cove-text-field-layout.patch` 维护，本版起进入 Cove 上游；发布流程固定 Cove 提交 `05e0b43`，不再在 CI 里打补丁。

### 安装说明

- macOS：打开 `.dmg`，把 `Ruwriter.app` 拖进「应用程序」。当前包没有 Apple 开发者签名与公证，首次打开请右键「打开」，或到「系统设置 → 隐私与安全性」允许。
- Windows：运行 `Ruwriter-v0.4.2-windows-x64-setup.exe` 安装。未签名，SmartScreen 提示时选择「更多信息 → 仍要运行」。
- Linux：`sudo apt install ./Ruwriter-v0.4.2-linux-x64.deb`，需要系统具备 Vulkan 与常用 X11 / Wayland 图形库。
- iOS 与 Android 需要各自的签名材料，本次不提供移动端安装包。

下载后可用同一 Release 里的 `SHA256SUMS.txt` 校验文件完整性。

## 已知限制

- 云同步依赖 GitHub CLI；未安装 `gh` 时面板会给出安装与登录提示。
- Gist 单文件有平台上限，超大文稿或附件不适合作为同步载体。
- macOS 包最低系统版本由 Cove 打包配置决定，目前为 macOS 26。
- 没有代码签名，首次运行会被系统拦截一次。
- Windows 高 DPI 下的鼠标点击定位仍在实机验证；如果遇到整体偏移或越往上越偏，请附上缩放比例与点击位置。
